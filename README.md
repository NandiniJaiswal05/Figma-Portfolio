# Nandini Jaiswal — Miniature Figma Portfolio/Product Experience

This is a zero-build, static website intentionally designed as a miniature Figma-like product experience rather than a normal portfolio.

## Files
- `index.html` — structure and portfolio content
- `styles.css` — complete UI/canvas styling
- `script.js` — interactions, navigation, command palette, prototype mode and demo playground

## Features
- Figma-style editor chrome
- Layers panel and selection state
- Design / Prototype / Inspect tabs
- Infinite-style canvas with frames
- Frame navigation and keyboard shortcuts
- Zoom and grid controls
- Presentation mode
- Command palette (`Ctrl/Cmd + K`)
- Interactive project cards
- PlaceLeet architecture inspector
- Working miniature PlaceLeet practice playground
- Scratchpad and code editor state persisted in localStorage
- Simulated code execution and hint flow
- Research visualization
- Responsive layout

## Deploy on Vercel
Upload the three files to GitHub and import the repository into Vercel.
Framework: Other / no build command.
Output directory: `/`.

## Deploy on GitHub Pages
Push the files to a repository and enable GitHub Pages from Settings → Pages.

## Before application submission
Replace the placeholder GitHub, LinkedIn and LeetCode URLs in `index.html` with the exact profile URLs. Also connect the résumé button to a hosted PDF if desired.

## Source
Portfolio facts are based on the supplied SDE resume. The site deliberately presents those facts in a product-style interface rather than adding unsupported employment claims.
